# Machine Learning 4 PMI

Esempi di Machine Learning per:
- Analisi predittiva (efficientamento processi)
- Creazione nuovi prodotti
- Utilizzo LLM

---

## Strumenti
- Orange
- Jupyter Notebook

---

## Contenuti
- `analisi_predittiva/`: Modelli predittivi per ottimizzazione processi
- `sviluppo_prodotti/`: Esempi per sviluppo nuovi prodotti
- `llm/`: Utilizzo di LLM per task aziendali

---
## Come usare
1. Clona la repo:
   `git clone https://github.com/chiatama/ml4pmi.git`
2. Apri i file `.ows` con Orange o `.ipynb` con Jupyter Notebook.
